# Subir GameHub a GitHub (paso a paso)

Cuenta: **igaviria0001-ops** · Nombre del repositorio: **`gamehub`** (así, en minúsculas)

## 1. Crear el repositorio (1 minuto)

1. Entra a <https://github.com/new> con tu cuenta.
2. **Repository name:** `gamehub`
3. Marca **Public** (GitHub Pages gratis necesita que sea público).
4. **No** marques «Add a README», ni .gitignore, ni licencia: tiene que quedar vacío.
5. Pulsa **Create repository**.

## 2. Subir los archivos

**Lo más fácil (y queda sincronizado conmigo):** escríbeme en el chat «listo, ya creé gamehub». Tu GitHub ya está conectado conmigo, así que subo todo de una (los 4 juegos con su código, la app y la página). Las mejoras que hagamos después las subo yo mismo ahí.

**Si lo quieres subir tú ya mismo:**

1. Descomprime `gamehub.zip` en tu computador.
2. En la página del repositorio nuevo, pulsa el enlace **«uploading an existing file»**.
3. Arrastra **solo la carpeta `docs`** (GitHub deja máximo 100 archivos por vez y esa carpeta trae todo lo que se juega).
4. Abajo, pulsa **Commit changes**.

El resto del código (unos 400 archivos) lo subo yo cuando me digas.

## 3. Encender la página (1 minuto)

1. En el repositorio: **Settings** → **Pages** (menú de la izquierda).
2. En **Build and deployment** → **Source**: elige **Deploy from a branch**.
3. **Branch:** `main` y carpeta **`/docs`** → **Save**.
4. Espera 1 o 2 minutos y abre: **<https://igaviria0001-ops.github.io/gamehub/>**

## 4. Instalarla como app

- **PC (Chrome o Edge) y Android:** botón **Instalar** arriba a la derecha (o *Ajustes → Instalar GameHub*).
- **iPhone / iPad:** ábrela en **Safari** → **Compartir** → **Agregar a inicio**.

## Cómo quedan las actualizaciones

- Cada cambio que se suba a `main` se publica solo en 1–2 minutos.
- La app (instalada o no) se da cuenta, muestra **«Hay una versión nueva»** y se actualiza con un toque; nunca en medio de una partida.
- **El progreso no se pierde:** récords, campañas, mundos, ajustes y torneos viven en el aparato de cada uno, aparte de los archivos de la app.
- Para que siga así: **no le cambies el nombre al repositorio ni a la cuenta** (cambia la dirección y el navegador la trataría como otra app).
- En *Ajustes → Tu progreso* está la **copia de seguridad** (guardar y restaurar), por si alguien cambia de celular.
